# 戦略的曖昧化

## 中核の主張

> 曖昧にしておいた方が将来の不確実を活用する上で有利なので故意に曖昧にすることがある
> 自分ならそうするであろうシチュエーションで明確化をしようとする人には「戦略的思考力が弱いんだな」と思う
> 別の表現: 不確実耐性

— Scrapbox `[戦略的曖昧化]`（2026-05-19 作成、出典: [[../../raw/nishio-nishio観察パターン.1hop.txt|nishio観察パターン 1hop ファイル]]）

## 逆向きの運用: 状況依存の明確化

同じページで本人が:

> もちろん逆に「明確化しましょう」と言うときもある
> 議論が不毛な水掛け論とか **曖昧な停滞** に進みそうだと感じたときに、明確化を掛ける
> 自分のリソース支払いが曖昧なケース: 放置すると予期せずたくさん支払わされる可能性がある（特に時間）

→ 戦略的曖昧化と意識的明確化は**同じ戦略思考の両側面**。
→ 外見からは [[../../raw/external_brain_in_markdown/pages/ダブルスタンダード.md|ダブルスタンダード]] に見えるが、本人の中では一貫している。

## [[曖昧な停滞.md|曖昧な停滞]] との対比

| | 戦略的曖昧化 | [[曖昧な停滞.md|曖昧な停滞]] |
|---|---|---|
| 主体 | 故意に曖昧にする | 意思決定のハンドルを握ったまま動かない |
| 効果 | 不確実性の活用 / 選択肢の保持 | 進捗の停止 |
| 解消 | 不要（むしろ維持） | 解消すべき |
| 判定 | 状況によって明確化に切り替える | 切り替え判断ができていない状態 |

→ 「曖昧」という同じ表面状態が、戦略か停滞かに分かれる。違いは **意識的なコントロールの所在**。
→ 「曖昧な停滞に進みそうと感じたら明確化を掛ける」発言は、本人がこの境界を能動的に監視している証拠。
