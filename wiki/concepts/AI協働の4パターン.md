# AI 協働の 4 パターン (A/B/C/D)

## 4 パターンの定義

[[../../raw/nishio-思考の結節点2025-10-29.1hop.txt|思考の結節点2025-10-29]] で提示された分類。

| | フロー | 代表実装 |
|---|---|---|
| **A** | 大量データ X → AI 要約 → 人間 | 2023年初期[[../topics/ブロードリスニング.md|ブロードリスニング]]、TTTC Scatter、Jigsaw Sensemaker、tttc-light-js |
| **B** | 大量データ X → 人間が問い → AI 回答 | 初期 RAG（チャンク+embedding+ベクトル検索） |
| **C** | AI が問い → 人間が回答 → 大量データ Y が生成 | AI インタビュアー（コンテキスト幅拡大で可能化） |
| **D** | データ X と Y の **結合の発見** が価値 | **本ページの新提案**（主観的興味深さ推定システムが第一弾） |

## 歴史的発展（コンテキスト幅の制約と解放）

- **2023年初期**: コンテキスト幅が狭い → embedding 前提（A も初期 B も）
- **コンテキスト幅拡大**: 「全部コンテキストに入れる」型の A が増える
- **広い C が可能に**: AI インタビュアーが現実的になった
- **C の Y が余る**: C のデータをどう活用するかが宙に浮いた
- **D の提案**: C の出力 Y を A/B/C の入力 X にし、X と Y の結合を発見することに価値を見出す

## C と D の哲学的差異

| | C | D |
|---|---|---|
| プロンプト設計 | 「引き出す」に重点 | 引き出した上で **関係する Xi を提示** |
| 価値の受け手 | **運営者**（データが欲しい） | **エンドユーザ**（気付きを得る） |
| 出力 | データ Y | 関係性 / 気づき |
| 「so what?」 | 起こる | 「自分にとっての意味」が即時に見える |

→ C は 2023〜2025 で多数実装されたが、エンドユーザ側から「色々聞かれて答えたけど so what?」という反応が出ていた。D はこの問いへの本人の答え。

## D を正当化する理論的基盤

D が成立するためには、「**気づき = 知らない領域への一歩先での新結合**」という認知モデルが必要。nishio は以下を基盤に置く:

1. [[../../raw/external_brain_in_markdown/pages/知らないことだけが気づきの対象になる.md|知らないことだけが気づきの対象になる]]（2025-01-29） — 既知の提示は「もう知ってる」を呼ぶだけ
2. [[../../raw/external_brain_in_markdown/pages/今持っている知識の一歩先の知識しか受け止められない.md|今持っている知識の一歩先の知識しか受け止められない]]（2023-12-14） — 「一歩先」だけが面白い（遠すぎてもダメ）
3. [[../../raw/external_brain_in_markdown/pages/情報の価値は人によって異なる.md|情報の価値は人によって異なる]]（2025-10-26） — 個人的体験こそ「まだ知らない」可能性が高い
4. [[../../raw/external_brain_in_markdown/pages/N=1でも重要な意見とは橋かもしれない.md|N=1でも重要な意見とは橋かもしれない]]（2025-10-22） — N=1 の重要意見 = 橋 = 予期せぬ新結合
5. [[../../raw/external_brain_in_markdown/pages/関係とは何だろう.md|関係とは何だろう]]（2018-10-10, エンジニアの知的生産術 5.2.5） — 類似だけが関係ではない（対立/包含/時間/因果/接続）

→ 1〜4 は「気付きの認知モデル」、5 は「結合の種類モデル」。D はこの 2 つを掛け合わせた実装路線。

## 「絞り切れていない」状態の指摘

> これは既存のシステムでも部分的に満たされていた顧客価値なんだが、ここ自体にフォーカスしてシステムが作られていたわけではなく副次的に満たされていた
> [[../../raw/external_brain_in_markdown/pages/構想力は問題を限定する能力.md|構想力は問題を限定する能力]] の図でいうところの適切に絞りきれていない状態

→ D は「副次効果としては存在したが、それを主目的に置いたシステムは無い」という空席を指している。
→ D 単独に絞ったシステム設計が次の発明対象。
