# 抽象化された空間での近傍探索

## 中心テーゼ（2026-06-04, 本人の解説）

> 高次元空間の中で近傍を探索しても球状の狭い空間しか探索できない。が、一旦低次元空間に降りると、その空間での近傍探索は高次元空間では円柱状の空間の探索になる。

つまり「**投影してから近傍探索する**」という操作は、元空間においては届かなかった広がりを射程に入れる**ジャンプの手段**である。

そして本質はこうである:

> 「低次元」というのはベクトル空間由来のメタファーであるので、実際に必要なのは低次元であることではない。投影先の空間での探索が投影元の空間の近傍探索では到達しないようなジャンプであること。

ジャンプ性は**必要条件であって十分条件ではない**（ハッシュ関数も同じ性質を持つから、それだけでは有用にならない）。

## 構造: 投影 → 探索 → 引き戻し

「抽象化された空間で近傍探索する」という操作はアナロジー・連想・知的生産のあちこちで同じ三段構造を取る:

1. **投影**: 元空間（高次元、複雑、生の現実）から、より粗い空間に写す
   - 線形射影: PCA / ランダム射影 / Dropout（軸を潰す）
   - 非線形: LSH / ニューラルネット / **LLMに2つのものの違いを捨象させる**
2. **投影先の空間で近傍探索**: 元空間では遠いものが、投影先では近くなる
   - 元空間では「球状」の狭い範囲しか見ないが、投影先での「球」は元空間に戻すと「円柱」になる
3. **引き戻し**: 投影先で見つけたものを元空間の具体性に戻す
   - メタファー → 別ドメインへの具体化
   - [[../../raw/external_brain_in_markdown/pages/対応付け、連想し、引き戻す.md|対応付け、連想し、引き戻す]]（『エンジニアの知的生産術』p.196）

[[../../raw/external_brain_in_markdown/pages/高次元においてコサイン類似度0.2は激レア.md|高次元においてコサイン類似度0.2は激レア]] は「元空間の近傍がいかに薄いか」の実証で、なぜ投影してから探索する操作が必要になるかの根拠となる。

## 投影は線形射影でなくてよい

[[../../raw/external_brain_in_markdown/pages/メタファー空間でGPT4に発散と抽象化をさせてから具体化する.md|メタファー空間でGPT4に〜]] の時点で本人は既に「ベクトル空間の射影」より広い操作を「投影」として扱っていたが、2026-06-04 の解説で明示的に一般化された:

- LLM に「2つのものの違いを捨象させる」のも投影の一種
- 「低次元」はベクトル空間由来の**メタファー**であって、本質要件ではない
- 本質要件 = **元空間の近傍探索では到達しないジャンプを生むこと**

## ジャンプ性は必要条件、十分条件ではない

> これは有用であることの十分条件ではない。ハッシュ関数なども同じ性質を持つからね。

「投影元の近傍探索では届かないところに飛ぶ」だけならランダムハッシュでも実現される。アナロジーや連想が**有用**であるためには、ジャンプに加えて「意味構造を保存する」ような追加条件が必要になる — ここは未整理。LSH の "Locality-Sensitive" がまさにこの条件を扱おうとした概念。

## どの軸を潰すか問題（オープンクエッション、word2vec時代から）

[[../../raw/external_brain_in_markdown/pages/アナロジーと次元削減.md|アナロジーと次元削減]] では:

> どの軸を選んで潰すかは [[バンディット問題]]

word2vec の頃から「どの軸に投影して異次元化するのか」がオープンクエッションだった、と 2026-06-04 に本人が振り返っている。

選択肢:
- ランダム選択（Dropout 型）
- 探索-活用トレードオフ（バンディット）
- LLM に「この対比は何の違いか」を聞いて軸を明示化させる（[[../../raw/external_brain_in_markdown/pages/メタファー空間でGPT4に発散と抽象化をさせてから具体化する.md|メタファー空間で〜]] の実例）
